insert a new element into an array using JavaScript. It focuses on building the logic manually, which is a common task in Data Structures and Algorithms (DSA) interviews.

Key Concepts:
The Challenge: When you insert an element in the middle of an array, existing elements must be shifted to the right to make space.
The Strategy: To avoid overwriting data, the process starts from the end of the array. Elements are moved one position to the right until the desired target index is reached.
Manual Implementation: Instead of relying on built-in methods, the video demonstrates using a for loop to iterate backwards through the array to perform these shifts.
Built-in Alternative: The video also briefly covers the JavaScript splice() method as a shortcut, while noting that interviewers typically prefer seeing the manual logic to test your problem-solving skills.
Example Logic:
Define an array and the new element you want to add.
Use a loop starting from the last index.
Shift each element to the next index.
Once the target position is reached, replace or insert the new value.

splice() method JavaScript me arrays ke saath kaam karne ka ek bahut hi powerful tool hai. Iska primary use array me se elements remove karna, naye elements add karna, ya existing elements ko replace karna hota hai.

Ek baat hamesha yaad rakhna: splice() original array ko change (mutate) kar deta hai.

 Static Array:
Ek aisa array jiska size program run hone se pehle hi fixed (set) kar diya jata hai. Isme ek baar jo length decide ho gayi, use baad me na toh badhaya ja sakta hai aur na hi ghataya ja sakta hai (jaise C/C++ me int arr[5];). Agar 5 elements ki jagah hai, toh 6th element add nahi kar sakte.
Dynamic Array:
Ek aisa array jiska size program chalte waqt automatically grow (badh) ya shrink (ghat) sakta hai. Isme fixed limit nahi hoti; jaise-jaise aap elements add (push) ya remove (pop) karte ho, ye memory ko apne aap adjust kar leta hai (jaise JavaScript ke saare arrays let arr = []).

Static Array:
Array kitne size ka hoga, ye fixed (pack) hota hai. Program run karne ke baad aap us array ka size chhota ya bada nahi kar sakte.

Example (C Language): Agar tune int arr[5]; banaya, toh poore program me usme hamesha max 5 hi dabbas (elements) honge. Agar 6th value user se input loge, toh error aayegi.
Dynamic Array:
Isme size fix nahi hota. Program run hote waqt jab aap user se input lete ho ya values insert/remove karte ho, toh array ka size apne aap grow (bada) ya shrink (chhota) ho jata hai.

Example (JavaScript): let arr = []; - Isme aap run time par push() karke 100 values bhi daal sakte ho aur pop() karke size 0 bhi kar sakte ho.
Aapne jo bola: "Static wo jo program karte waqt banaya, Dynamic wo jo run time par user se value lekar banaya."

Real Reality: Dono hi arrays run time par bante aur run time par input le sakte hain. Key difference ye hai ki Static Array ka size fix (bound) rehta hai, jabki Dynamic Array zarurat ke hisaab se expand/resize ho jata hai.

let index;	undefined	Memory allocate ho gayi hai, par koi value assign nahi hui.
var index;	undefined	Same as let, default value undefined hoti hai.
const index;	SyntaxError	Error aayega! const ke saath bina value diye chhod nahi sakte (Missing initializer in const declaration).
let index = null;	null	null tabhi banta hai jab aap intentionally (jaan-boojhkar) null assign karte ho.
ifference Between undefined vs null:
undefined: JavaScript khud deta hai jab kisi variable me value daalna bhool jate ho ya assign nahi karte.

null: Developer (aap) khud deta hai ye batane ke liye ki "abhi ye variable empty/khali hai".
