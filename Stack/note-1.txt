JavaScript me variables memory me kaise store aur pass hote hain, ye unke Data Type par depend karta hai.

Step-by-Step Logic Explanation
JavaScript me data types do tarah ke hote hain:
Primitive Types: number, string, boolean, null, undefined, symbol, BigInt (Pass by Value)
Non-Primitive / Reference Types: Object, Array, Function (Pass by Reference)
1. Pass by Value (Primitive Types)
Jab aap kisi primitive value ko function me pass karte ho ya kisi doosre variable me copy karte ho, to memory me uski ek nayee copy (independent copy) banti hai. Original variable me koi change nahi hota.
2. Call / Pass by Reference (Non-Primitive Types)
Jab aap kisi Array ya Object ko function me pass karte ho, to actual values/data copy nahi hote. Inka Memory Address (Reference) pass hota hai.
Impact: Function ke andar agar aap object ya array me koi change (modify/mutate) karte ho, to wo badlaav original object/array me bhi reflect hoga, kyunki dono same memory location ko point kar rahe hain.
Code Execution Example
Example 1: Pass by Value vs Pass by Reference

// --- Pass by Value (Primitives) ---
let num = 10;

function updateNumber(x) {
    x = 20; // Sirf local copy change hui
}

updateNumber(num);
console.log(num); // Output: 10 (Original change nahi hua)


// --- Pass by Reference (Arrays/Objects - DSA Context) ---
let arr = [1, 2, 3];

function modifyArray(data) {
    data.push(4); // Reference par kam hua, memory me modification hua
}

modifyArray(arr);
console.log(arr); // Output: [1, 2, 3, 4] (Original array change ho gaya!)

Key Takeaway for DSA
DSA me jab aap Arrays, Linked Lists, Trees, ya Graphs ke sath kaam karte ho, to reference ka logic sabse important hota hai:
In-place Operations: Jab DSA problems me "in-place" modify karne ko kaha jaye (jaise Stack, Queue implementation, ya Array reversal), tab aap same reference ko modify karte ho.
Accidental Mutation: Agar aapko original data safe rakhna hai, to reference directly pass karne ke bajaye Shallow Copy ([...arr]) ya Deep Copy karna padta hai.
Reassignment vs Mutation:
Modifying property/element (arr[0] = 10 ya arr.push()) ➔ Original Reference change hoga.
Reassigning whole variable (arr = [1, 2, 3]) ➔ Local scope me reference ka link toot jata hai, original unchanged rehta hai.

Stack Data Structure ka use karke ek string ko reverse karne ka tarika samjhaya gaya hai. Stack ka fundamental rule LIFO (Last In, First Out) hota hai, jo is kaam ke liye perfect hai.

1. Core Logic aur Intuition
Stack ki sabse badi khasiyat ye hai ki jo element sabse last mein insert (push) kiya jaata hai, wohi sabse pehle bahar (pop) nikalta hai. Agar hum ek string ke har character ko ek-ek karke stack mein daalein, toh stack ke top par wahi character hoga jo string ke end mein tha. Jab hum in characters ko ek-ek karke stack se nikalenge (pop), toh humein wahi characters reverse order mein milenge.

2. Step-by-Step Logic
Input Handling: Sabse pehle apni string ko lo aur usse ek array ya list mein convert karo taaki har character ko individually access kar sakein.
Push Operation: Ek loop chalao jo string ke har character ko pakde aur stack mein 'push' (add) karta jaye. Isse string ka pehla character stack ke bottom par hoga aur aakhri character top par.
Pop Operation: Ab ek doosra loop chalao jo stack khali hone tak characters ko 'pop' (remove) karta rahe. Kyunki stack LIFO follow karta hai, isliye pop karne par aakhri character sabse pehle nikal kar ayega, phir usse pehle wala, aur isi tarah poori string reverse ho jayegi.
3. Concrete Example (Dry Run)
Maano humein "HELLO" string ko reverse karna hai:

Push Process:

H ko stack mein daala (Stack: H)
E ko daala (Stack: H, E)
L ko daala (Stack: H, E, L)
L ko daala (Stack: H, E, L, L)
O ko daala (Stack: H, E, L, L, O) - O ab top par hai.
Pop Process (Reverse):

Pehli pop command: O bahar aaya.
Doosri pop command: L bahar aaya.
Teesri pop command: L bahar aaya.
Chauthi pop command: E bahar aaya.
Paanchvi pop command: H bahar aaya.
Resulting sequence: O-L-L-E-H. Is tarah stack ne automatically string ko reverse kar diya.
